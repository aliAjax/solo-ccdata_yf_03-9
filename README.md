# 转写稿离线脱敏审校台

纯前端、**离线运行、不接后端**：直接用浏览器打开 `index.html` 即可（同目录的 `app.js` 必须保留）。

## 功能

1. **批量导入**：粘贴多条转写稿，空行分隔；短首行作为文稿名（保留在正文中，不丢数据），也可显式写 `标题：客服来电`。
2. **自动标引五类敏感信息**：手机号、邮箱、证件号（15/18 位）、银行卡（Luhn 校验，支持分隔符）、地址（行政区划 + 门牌后缀）。
3. **人工审校**：正文划选即可补标；点击高亮可改判类型、逐字调整边界、取消误标（可恢复），人工补标可彻底删除。
4. **固定优先级合并**：证件号 &gt; 银行卡 &gt; 手机号 &gt; 邮箱 &gt; 地址。重叠 / 嵌套 / 相邻（含传递相邻）命中聚为一簇，按「类型优先级 → 人工优先 → 跨度更长 → 位置靠前」选出唯一胜出片段（span 取并集），**被压制候选逐条列出原因**（嵌套 / 重叠 / 跨类型相邻 / 同类型相邻合并）并可一键改采用。
5. **代号登记**：`P/M/I/B/A + 三位序号`。同一原始值跨文稿同号（手机号/邮箱大小写、卡号分隔符等先规范化），不同原始值绝不撞号，序号只增不复用。
   - **相同原文、不同含义**（同一串在一篇是证件、另一篇是银行卡）会作为跨类型冲突列出，解决前相关片段不脱敏、不能确认。
6. **确认与导出**：确认后预览脱敏稿（`〔P001〕` 形式），页面先做「映射恢复逐字自检」，再导出：
   - `masked.txt`：脱敏文本；
   - `recovery-mapping.json`：代号 → 每处原文及出处的映射清单，可恢复原文（与脱敏稿分开保管）；
   - `audit-chain.json`：哈希链审计记录。
7. **可校验审计**：导入、补标、删除、改判、调边界、取消误标、撤销、重做、确认、返回修改全部上链（SHA-256，前链哈希 + 操作后状态指纹）。刷新或重新导入后自动校验：改动任一条历史、删记录、在审计之外改文稿/标记都会被发现。
8. 状态存 localStorage，Ctrl+Z / Ctrl+Y 撤销重做。

## 文件

- `index.html`：界面与交互
- `app.js`：检测 / 合并 / 代号 / 脱敏恢复 / 审计哈希链核心（无第三方依赖，UMD，可被 Node 引用）
- `test/run.js`：核心逻辑端到端验证（45 项断言）
- `test/dom.js`：jsdom 界面冒烟（26 项断言，需 jsdom）

## 验证

```bash
node test/run.js
node test/dom.js   # 需 npm i jsdom
```

覆盖：重叠/嵌套/相邻合并及压制清单、相同文本不同含义冲突、误标取消→撤销→重做、映射恢复原文（含缺/多映射报错）、审计链与状态指纹的篡改检出、刷新序列化往返。
